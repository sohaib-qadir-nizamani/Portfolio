# Portfolio

A modern, production-quality Front-End Developer portfolio built with React, Vite, Tailwind CSS, and React Router.

## 🚀 Project Goals

This portfolio is being built to showcase:

- Front-End Development skills
- React ecosystem expertise
- UI/UX design principles
- Production-ready coding practices
- Responsive and accessible web applications
- AI-assisted development workflow

## 🛠️ Tech Stack

- React
- Vite
- React Router
- Tailwind CSS
- JavaScript (ES6+)

## 📂 Planned Features

- Modern Hero Section
- About Me
- Technical Skills
- Featured Projects
- Professional Experience
- AI-Assisted Development Workflow
- Services
- Education & Training
- Contact Form
- Dark/Light Theme
- Responsive Design
- Accessibility Best Practices
- High Lighthouse Scores
